HUQUQSAVOLJAVOB — TELEGRAM БОТ ВА МИНИ ИЛОВА (MINI APP)
Бошқа аккаунтга кўчириш ва ишга тушириш бўйича йўриқнома

============================================================
ФАЙЛЛАР ТАРКИБИ
============================================================
railway.json            — Railway созламаси (Dockerfile орқали йиғиш, доим қайта ишга тушириш)
index.html              — платформанинг веб-версияси (GitHub Pages учун, ботга шарт эмас)
bot/bot.py              — бот ва веб-сервер (Mini App, админ панел, API)
bot/requirements.txt    — Python кутубхоналари
bot/Dockerfile          — сервер учун контейнер
bot/.env.example        — созламалар намунаси (.env номи билан нусха олинади)
bot/sozlash.py          — компьютерда биринчи марта созлаш (саволлар бериб .env ёзади)
bot/ISHGA_TUSHIRISH.bat — Windows'да икки марта босиб ишга тушириш
bot/web/app.html        — Mini App (платформа) шаблони
bot/web/loader.html     — Mini App юкловчи саҳифаси
bot/web/admin.html      — админ панел сайти
bot/web/oferta.txt      — фойдаланиш шартлари ва оммавий оферта матни (таҳрирлаш мумкин)
bot/data/platform_bank.json — 20 017 та савол-жавоб, матнлар, расмлар (Mini App учун)
bot/data/bank.json      — бот чатидаги савол-жавоблар базаси
bot/data/welcome.png    — /start даги скриншот
bot/data/img/*.png      — байроқ расмлари (ботда расмли саволлар учун)

Фойдаланувчилар, тўловлар, чеклар, фикрлар — bot.sqlite3 базасида (сервер дискида) сақланади.
Янги аккаунтга кўчирганда база янгидан бошланади (эски фойдаланувчилар ўтмайди).
Эскисини ҳам кўчириш керак бўлса — эски сервердаги /data/bot.sqlite3 ва /data/receipts папкасини
янги серверга нусхалаш керак.

============================================================
1-ҚАДАМ. ТЕЛЕГРАМ
============================================================
1) Бот: @BotFather → /newbot (ёки мавжуд бот) → API Token нусхаланади.
   Бот номини (масалан, huquqsavoljavob_bot) ёзиб қўйинг.
2) Admin ID: @userinfobot га ёзинг — сизнинг ID рақамингиз чиқади.
3) Канал: ботни каналга АДМИН қилиб қўшинг (обунани текшириш учун шарт).

============================================================
2-ҚАДАМ. GITHUB (янги аккаунт)
============================================================
1) github.com да янги репозиторий очинг (Private бўлиши мумкин).
2) Шу файлларни папка тузилиши сақланган ҳолда юкланг:
   railway.json ва index.html — илдизда, қолганлари — bot/ папкасида.
   (GitHub сайтида: Add file → Upload files → папкани судраб ташланг.)
   ДИҚҚАТ: .env файлини (токен) GitHub'га юкламанг.

============================================================
3-ҚАДАМ. RAILWAY (сервер, 24/7)
============================================================
1) railway.com → New Project → Deploy from GitHub repo → репозиторийни танланг.
   (GitHub ҳисобига Railway иловасига шу репозиторийга рухсат беринг.)
2) Сервис → Settings → Networking → Generate Domain (порт 8080).
   Чиққан манзил, масалан: https://xxxx.up.railway.app
3) Сервис → Volumes (ёки ўнг тугма → Attach Volume) → Mount path: /data
   (база янгиланишларда йўқолмаслиги учун шарт).
4) Сервис → Variables → қуйидагиларни қўшинг:
     BOT_TOKEN            = BotFather токени
     BOT_USERNAME         = бот номи (@ сиз)
     ADMIN_IDS            = сизнинг ID (бир нечта бўлса вергул билан)
     WEBAPP_URL           = 2-банддаги манзил (охирида / йўқ)
     CHANNEL              = @канал_номи
     CHANNEL_URL          = https://t.me/канал_номи
     ADMIN_PANEL_PASSWORD = браузердан кириш пароли (ихтиёрий)
5) Deploy тугайди → Logs'да "Start polling" чиқса, бот ишлаяпти.

============================================================
4-ҚАДАМ. МИНИ ИЛОВАНИ УЛАШ (ихтиёрий, тавсия этилади)
============================================================
@BotFather → /mybots → бот → Bot Settings → Configure Mini App → Enable →
URL: WEBAPP_URL (масалан https://xxxx.up.railway.app/)
Шунда бот профилида «Open» тугмаси чиқади. Чатдаги пастки чап тугма бот ишга тушганда
ўзи ўрнатилади.

============================================================
5-ҚАДАМ. АДМИН ПАНЕЛДА СОЗЛАШ
============================================================
Ботга /admin → «Admin panelni ochish» (ёки браузерда WEBAPP_URL/admin + парол).
 • Тарифлар ва созламалар: тарифлар (ой/кун, нарх; 0 сўм — дарҳол очилади),
   карта рақами, карта эгаси Ф.И.Ш., QR код, админ телефони, тўлов йўриқномаси;
   «Ҳамма учун бепул давр»; «Бот ва иловани вақтинча тўхтатиш».
 • Сўровлар / чеклар: чекни кўриш, муддат ва суммани (чегирма) танлаб тасдиқлаш ёки рад этиш.
 • Фойдаланувчилар: қидириш, муддат бериш/узайтириш, ёпиш.
 • Тўловлар, Фикрлар (жавоб бериш), Хабар юбориш.

Ботдаги буйруқлар (админ):
 /admin — ҳисобот ва панел тугмаси
 /ochish ID [ой] [кун] — тўлиқ киришни очиш (масалан /ochish 123456 0 10 — 10 кунга)
 /yopish ID — ёпиш
 /xabar матн — ҳамма фойдаланувчиларга хабар

============================================================
КОМПЬЮТЕРДА СИНАБ КЎРИШ (Windows)
============================================================
Python 3.10+ ўрнатинг → bot папкасидаги ISHGA_TUSHIRISH.bat ни икки марта босинг →
саволларга жавоб беринг. Бот чатда ишлайди; Mini App учун эса https манзил керак
(шунинг учун доимий ишлатиш учун Railway тавсия этилади).

============================================================
ФОЙДАЛАНУВЧИ ЙЎЛИ
============================================================
/start → телефон рақамини юбориш → фойдаланиш шартларига розилик → илова.
Демо: ҳар бир дарслик мавзусидан ва ҳар бир ҳужжатдан 5 тадан савол.
Тўлиқ кириш: каналга обуна → тариф → (пуллик бўлса) чек → админ тасдиғи.
