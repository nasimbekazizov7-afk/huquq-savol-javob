@huquqsavoljavob_bot — СОЗЛАШ ВА ИШГА ТУШИРИШ

1. ТОКЕН
   BotFather → /mybots → @huquqsavoljavob_bot → API Token. Нусха олинг.
   .env.example файлидан нусха олиб, номини .env қилинг ва ичига ёзинг:
   BOT_TOKEN, ADMIN_IDS (ўз ID рақамингиз — @userinfobot дан билинг).

2. КАНАЛ
   Ботни @huquqsavoljavob каналига АДМИН қилиб қўшинг (ҳеч қандай ҳуқуқ бермаса ҳам бўлади).
   Акс ҳолда бот аъзоликни текшира олмайди.

3. ТЎЛОВ (2 йўл)
   а) Автоматик: BotFather → /mybots → бот → Payments → Payme ёки Click ни улаб, берилган
      токенни .env даги PAYMENT_PROVIDER_TOKEN га ёзинг. Фойдаланувчи ботнинг ичида тўлайди,
      тўловдан кейин тўлиқ кириш ўзи очилади.
   б) Қўлда (токен бўлмаса): бот фойдаланувчига /tolov_matni да ёзилган йўриқномани кўрсатади
      (масалан, карта рақами). Фойдаланувчи чек расмини ботга юборади → сизга келади →
      «✅ Ochish» тугмасини босасиз.

4. ИШГА ТУШИРИШ
   Windows: Python 3.10+ ўрнатинг, ISHGA_TUSHIRISH.bat ни икки марта босинг.
   Сервер (тавсия — бот 24/7 ишлаши учун): docker build -t huquqbot . && docker run -d --restart always --env-file .env -v $PWD/bot.sqlite3:/app/bot.sqlite3 huquqbot
   ёки: pip install -r requirements.txt && python bot.py

5. АДМИН БУЙРУҚЛАРИ (ботда)
   /admin — ҳисобот ва буйруқлар
   /narx 500000 — тўлов миқдорини ўзгартириш
   /ochish ID, /yopish ID — тўлиқ киришни қўлда очиш/ёпиш
   /tolov_matni ... — қўлда тўлов йўриқномаси
   /xabar ... — барча фойдаланувчиларга хабар

КИРИШ ДАРАЖАЛАРИ
   Демо: ҳар бир дарсликнинг I боби, 35 та ҳужжатнинг ҳар биридан 1–10-саволлар.
   Каналга аъзо: + II боблар, ҳужжатларнинг 11–20-саволлари.
   Тўлов: барча саволлар (20 017 та).
Маълумотлар: data/bank.json (платформадаги саволлар билан бир хил), фойдаланувчилар — bot.sqlite3.
